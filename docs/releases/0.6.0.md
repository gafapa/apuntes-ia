# Apuntes IA 0.6.0

## Highlights

- Generated visuals are previewed in Step 5 and enter the notes only after **Aceptar**. Images, diagrams, charts, maps and molecules support this review step.
- Expanded maps include physical features, regional data, historical borders, routes and blank activity maps.
- Existing-note import uses its own progress and review modal. Exercises remain separate from theory, import diagnostics appear in Step 4 and PDF image extraction preserves embedded raster images.
- Claude and Codex subscription usage appear independently, and finished agent jobs can be cleared without removing active work.
- The redesigned note-and-pencil icon is used throughout the interface and desktop assets.

## Performance and reliability

- Selective React subscriptions, memoized agent messages, cached drawings, lazy editor/catalogue loading and one shared KaTeX implementation reduce unnecessary startup and rendering work.
- Section summaries and source-search indexes are cached with invalidation for external changes and bounded memory use. Independent document-state reads run concurrently.
- Synthetic local benchmarks reduced repeated 80-section listing from roughly 125 ms to 4 ms and repeated source search from roughly 136 ms to 3 ms. The main JavaScript bundle decreased from 1.64 MB to 0.93 MB. These results do not imply faster cloud model inference.
- Atomic persistence, explicit corrupted-state errors, staged backup restoration and complete-upload checks protect stored work.

## Security and maintenance

- Public downloads validate and pin DNS answers, check redirects and enforce streamed size limits.
- Loopback HTTP/WebSocket boundaries, production security headers, exact Electron navigation origins and data-file containment are enforced.
- Dependencies include Electron 44.7.0; npm audit reports zero advisories at publication preparation time.
- Bundled Pandoc/Typst downloads and cached binaries are checked with SHA-256. CI actions are pinned and releases remain drafts until all platform builds succeed.

## Validation

All 63 automated tests, TypeScript checks and the production build passed locally. The release workflow repeats validation on Windows, macOS and Linux before publishing their artifacts.
